    EEG Recording

    BrainVision ActiCHamp
    This is the system setup we have in EEG Room 101. We use system 1 to monitor and record EEG data, while system 2 presents stimuli and sends markers to the EEG device. System 2 is mirrored in the participants' seating room.
    1. First step, turn on both systems.
    2. Connect the EEG amplifier with the battery as per the connection shown

    3. Now we’ll connect the EEG electrode set and the ground electrodes. Be very careful while handling these wires, as they are very delicate.

    4. Connect the first electrode set (Green colour, marked 1-32) and the ground electrode as shown in the photo. If you need a 64-channel setup, connect the appropriate electrode set to the next slot. For a 128-channel setup, connect the 4 electrode sets in their respective slots in order.

    5. Complete setup

    6. Now insert this dongle (UR13827) into system 1

    7. Now open BrainVision Recorder

    8. This is the main interface

    1. Click on File, then New Workspace

    2. This pop-up window will open up. Click the Browse button next to Raw File Folder, then select the folder where you want to keep your workspace. Then Click Next

    3. This pop-up window will open next. Click on Scan for Amplifier. It will automatically scan the number of connected electrodes with their labels. Set the sampling rate as per your requirements. Set the reference channel number as required. At the bottom of the pop-up window, you will see a button named Use Electrode Position File. Make sure the proper channel location file (.bvef) has been selected. Then click Next.

    4. This pop-up window will open. If you need to set up filters, you can do so here; otherwise, click Next

    5. This pop-up window will open next. If you want to visualise real-time average segmentation, you can do so here; otherwise, click Next

    6. You will see this window to save your workspace. Name it properly and save

    7. Now you can click on File and select Open Workspace

    8. After selecting your workspace, its name should appear in the bottom right corner

    9. Now click on Impedance check

    10. It will open this interface

    11. You can change the colour limit according to the impedance values (Green for 0-10 KOhm, Yellow to Red for 10-30 KOhm).

    12. Now you can start the capping part.
    13. Make sure that the participant reads the information sheet and signs the consent form.
    14. Measure the head size
    15. Clean the forehead and mastoid properly.
    16. Put the Cap on
    17. First, place the ground electrode, then the remaining electrodes one by one, properly. Handle all electrodes very carefully.
    18. Once you are satisfied with the impedance level of all electrodes, you are ready to record.
    19. Click on the Record button to start recording

    Check after Recording

    Once you have recorded your first data, check the following information

    1. Number of channels recorded
    2. Sampling rate
    3. Channel Labels for the given electrode set
    4. Channel Location
    5. Stimulus Markers Labels
    6. Stimulus Markers Time
